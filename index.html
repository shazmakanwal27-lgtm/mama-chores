📖 How Mama Chores Works
Your complete guide in 2 minutes
🌸 What is Mama Chores?

This is your mom brain on an app. It holds everything a single mom juggles: cooking, cleaning, groceries, school drop/pickup, appointments, birthdays, holidays. No login needed, works offline, saves on your phone automatically. Made for solo mamas doing it all.

☀️ Tab 1: TODAY

What it shows: Only tasks for TODAY sorted by time (7am breakfast, 3pm pickup).
How to use: Check off tasks as you do them. Tap the circle ✓. See progress 0/8 → 8/8. Stats on top show Today, Week, Month progress.
Pro tip: Use category chips (Meals, School, Events) on top to filter. Tap "Meals" to see only cooking tasks.

🗓️ Tab 2: WEEK

What it shows: Visual week grid Mon-Sun. Each day shows dots for tasks: 🍳 Meal, 🧹 Cleaning, 🎒 School, 🎉 Birthday.
How to use: Quickly see which days are busy. Below grid: how many tasks done per category this week.
Why useful: Single moms can see "Thursday is packed, move grocery to Wednesday".

📆 Tab 3: MONTH

What it shows: Full calendar. Dots on days you have tasks. Tap any date → see tasks for that date below.
How to use: Tap a future date (e.g. Dec 15) then add task at bottom - it will be added to that date. Great for adding birthdays months ahead.
Monthly Summary: Shows % done this month + count per category. Motivates you: "78% done this month!"

🍳 Tab 4: MEALS - Breakfast, Lunch, Dinner

What it shows: 7 days × 3 meals = 21 boxes. Mon: Breakfast/Lunch/Dinner, Tue: Breakfast/Lunch/Dinner... etc.
How to use:
1. Type what you will cook: e.g. Mon Breakfast = "Pancakes + Berries", Lunch = "Chicken Wrap", Dinner = "Pasta"
2. It saves automatically.
3. Scroll down to 🛒 Grocery List
Auto-Grocery Magic: Click "🪄 Auto-Generate from Meals" button. App reads all 21 meals and creates shopping list:
- Pancakes → adds Flour, Eggs, Milk, Berries
- Pasta → adds Pasta, Tomato Sauce, Cheese
- No duplicates. Shows which meal it came from.
Manual: You can still add "Milk" manually.

🔔 Tab 5: REMINDERS - Never Miss Birthdays!

How to set reminder:
1. When adding any task, choose reminder: "At time", "10 min before", "1 hour before", "1 day before", "1 week before"
2. For birthdays: Always choose "1 day before" or "1 week before" so you have time to buy gift! 🎁
What happens: If you enabled phone alerts (tap Enable button), your phone will buzz at that time even if app is closed. On iPhone, you must Add to Home Screen first for alerts to work.
Sections:
- Upcoming (next 7 days): All reminders coming
- Birthday Reminders: Only tasks with "birthday" in title - so you see all birthdays in one place
- All Reminders: Every reminder you set

🛒 How Grocery Works

- Add items manually: Type "Milk" + Add
- Auto-generate: Reads your meal plan + creates ingredients list
- Check off when bought ✓
- Shows where item came from: "from: Mon Dinner: Pasta"

Do this once, then app opens like real app from home screen with pink icon!

💡 Tips for Single Mamas

• Add all birthdays at start of month in Month view
• Use 1 week reminder for birthdays, 30 min for school pickup
• Sunday night: Plan meals for week + hit Auto-Generate Grocery
• Check off tasks - seeing progress keeps you motivated 🔥 Streak counts days you complete tasks
• Everything saves on phone, no one else sees it, 100% private
